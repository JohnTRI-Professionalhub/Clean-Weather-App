# Clean Weather App

A polished weather dashboard with live city search, current conditions, and a 5-day forecast.

## Overview

This project was built as a cleaner, more modern take on a standard weather app UI. It focuses on readability, visual polish, and a smoother browsing experience than typical card-heavy layouts.

## Features

- live city search with suggestions
- current weather conditions
- 5-day forecast
- sunrise, sunset, moonrise, and moonset data
- responsive glassmorphism-inspired interface
- no API key required

## Data Source

Weather and geocoding data are powered by [Open-Meteo](https://open-meteo.com/).

## Tech Stack

- HTML
- CSS
- JavaScript

## Run Locally

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```
